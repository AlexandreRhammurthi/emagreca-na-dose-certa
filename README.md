# Dose Certa

Protótipo responsivo de um simulador visual para seringas de insulina U-100. O cálculo usa a apresentação completa do frasco (`mg / mL`), a dose prescrita e a capacidade da seringa.

## Executar

Abra `index.html` diretamente no navegador ou inicie um servidor local:

```powershell
python -m http.server 8000
```

Depois, acesse `http://localhost:8000`.

> Ferramenta educativa. Não substitui orientação de um profissional de saúde.
